# Webhook Receiver Demo

Small FastAPI service for receiving local webhook deliveries from the Reliable Event Delivery Platform.

It exposes:

- `POST /webhook` - receives webhook events
- `GET /events` - shows recent received events
- `GET /health` - health check
- `GET /docs` - FastAPI Swagger UI

## Setup

```bash
cd /Users/mihir/dev-mihir/Projects/webhook-receiver
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

If you want to verify signed webhooks, set `WEBHOOK_SIGNING_SECRET` in `.env` to the endpoint signing secret generated by the webhook platform.

For now, the webhook platform does not return the endpoint secret in `POST /v1/endpoints`, so leave `WEBHOOK_SIGNING_SECRET` blank until that pending item is implemented or you manually copy the secret from the database.

## Run Locally

```bash
uvicorn main:app --reload --port 4000
```

Open:

```text
http://localhost:4000/docs
```

## Expose With ngrok

Install and authenticate ngrok from:

```text
https://ngrok.com/download
```

Then expose the local receiver:

```bash
ngrok http 4000
```

ngrok will print a public URL like:

```text
https://abc123.ngrok-free.app
```

Use this endpoint URL in the webhook platform:

```text
https://abc123.ngrok-free.app/webhook
```

## Register This Receiver In The Webhook Platform

Start the webhook platform API and worker:

```bash
cd /Users/mihir/dev-mihir/Projects/webhooks-project
npm run dev:api
npm run dev:worker
```

Register the receiver endpoint:

```bash
curl -X POST http://localhost:3000/v1/endpoints \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://abc123.ngrok-free.app/webhook",
    "event_types": ["payment_success"]
  }'
```

Send an event:

```bash
curl -X POST http://localhost:3000/v1/events \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "event_type": "payment_success",
    "payload": {
      "invoice_id": "inv_123",
      "amount": 4999
    }
  }'
```

Inspect received events:

```bash
curl http://localhost:4000/events
```

## Signature Verification

When `WEBHOOK_SIGNING_SECRET` is set, this receiver verifies:

```text
X-Event-ID
X-Timestamp
X-Signature
```

Expected signature format:

```text
signed_payload = timestamp + "." + raw_request_body
signature = HMAC_SHA256(signing_secret, signed_payload)
X-Signature = sha256=<hex_digest>
```

The receiver rejects:

- Missing signature headers
- Invalid timestamps
- Timestamps outside `MAX_TIMESTAMP_SKEW_SECONDS`
- Invalid HMAC signatures
- Invalid JSON bodies

It also marks duplicate events using `X-Event-ID`.
